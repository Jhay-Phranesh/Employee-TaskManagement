# Employee Task Management System

A FastAPI-based Employee Task Management System with JWT authentication, SQLAlchemy ORM, SQLite database, project-based task assignment validation, log rotation, unit testing, and GitHub Actions CI.

## Features

- User Registration
- User Login with JWT
- Create Projects
- Create Employees
- Create Tasks
- Assign Tasks
- Update Task Status
- Project-based Validation
- Log Rotation
- Unit Tests
- GitHub Actions CI

## Tech Stack

- FastAPI
- SQLite
- SQLAlchemy
- JWT
- Passlib
- PyTest
- GitHub Actions

## Run Application

```bash
uvicorn app.main:app --reload
